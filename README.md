# 云海修仙录

一个使用 React、TypeScript、Vite、Tailwind CSS 与 HTML Canvas 构建的中国古风修仙横版动作游戏。

## 技术栈

- React 19 + TypeScript 5
- Vite 7 + Tailwind CSS 4
- HTML Canvas 2D 游戏引擎 + Web Audio API
- `vite-plugin-singlefile` 单文件构建打包

## 核心系统

1. **角色与五行灵根系统**：
   - **基础属性**：威力（统领剑法与术法伤害）、护体真元（防御减伤）、气血上限、灵力上限。每次小升级均匀小幅提升，大境界突破大幅飞跃。
   - **进阶属性**：神识（影响会心与机缘）、身法（影响移速、跳跃高度与免伤闪避率）、会心率、会心伤害。升级不提升，只在大境界突破与装备词条中加成。
   - **五行灵根（五边形阵盘）**：金、木、水、火、土五项灵根数值，开局随机分配（总和固定为 50，单项 $\ge 0$），支持开局前重新洗髓。每点灵根提升对应属性法诀 0.5% 威力。
2. **万法自修与秘籍系统**：
   - 散修开局仅持凡剑与近身普攻，全系法诀（破岳、离火、玄冰箭、游龙剑阵、巨剑术、万剑决、天雷决、缩地成寸、御剑飞行等）及心法全靠技能书参悟。
   - K 键法诀管理面板支持自由将已学技能装备到 1~9 快捷槽，鼠标悬停即时展示详细数值、伤害期望与灵根加成。
3. **法宝与心法系统**：
   - BOSS 掉落专属法宝（乾坤珠：每5秒免灵力自动释放攻击法诀；青竹剑：四柄飞剑环绕切割）。
   - 被动心法（强身健体、灵力护体、灵力泉涌、遁光）学会即生效。
4. **纵深地图与山海图**：
   - 包含云隐村、青岚灵田、碧竹药林、凌云绝壁（下段/中段/山顶）、赤砂古道、断云剑峡、血月妖宫、演武场及作者测试场。
   - 支持多层平台、绳索、空中浮石隐境与 2D 星轨山海图传送。
5. **作者测试场与控制台**：
   - 暂停菜单可一键开启作者模式，进入作者测试场（`m_author`）可随时打开控制台，支持随意学习技能、召唤任意敌人与获取全部法宝。
